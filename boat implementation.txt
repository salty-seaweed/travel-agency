REVISED STRUCTURE:
1. BACKEND MODELS
A. Boat Model (The physical boats)
- name (e.g., "38ft Premium Sportfishing")- description- boat_type (sportfishing, center_console, etc.)- specifications:  - length  - engines (e.g., "Triple Mercury 300HP")  - cruising_speed  - top_speed  - capacity  - fuel_tank- features:  - cabin (yes/no)  - toilet (yes/no)  - shower (yes/no)  - sound_system (yes/no)  - etc.- departure_location- is_featured- images/videos
B. BoatActivity Model (What you can do)
- name (e.g., "Big Game Fishing", "Trolling", "Island Hopping")- description- activity_type (fishing, excursion, wildlife_watching)- duration_options (half_day, full_day, custom)- suitable_boats (M2M with Boat)- min_participants- max_participants- difficulty_level- includes (JSON: gear, equipment, etc.)- is_featured- images
C. BoatPackage Model (Silver/Gold packages)
- name (e.g., "Silver Package - 38ft", "Gold Package - 26ft")- boat (FK to Boat)- package_tier (silver, gold)- price- currency- duration (8 hours full day)- description- includes (JSON array)- activities_included (M2M with BoatActivity)- special_offers (e.g., "Year-End 20% OFF")- booking_notice (e.g., "48 hours advance")- is_active- display_order
D. BoatBooking Model (For tracking inquiries)
- customer info- selected_activity (FK)- selected_boat (FK, optional)- selected_package (FK, optional)- preferred_date- participants- special_requests- status (inquiry, confirmed, completed)
